# Civic Campus

Repository privat untuk proyek Civic Campus.

## Ringkasan
Proyek ini berfokus pada pengembangan sistem manajemen fasilitas dan insiden untuk lingkungan kampus, termasuk dokumentasi desain, arsitektur, dan spesifikasi produk.

## Struktur
- `docs/`: dokumentasi proyek, termasuk desain sistem, arsitektur, dan PRD.

## Penggunaan
1. Clone repository:
   ```bash
   git clone https://github.com/Nyot-Nyot/civic_campus.git
   ```
2. Lihat dokumen di folder `docs/`.

## Kontak
Jika perlu pembaruan, tambahkan isi dan dokumentasi proyek di repository ini.
